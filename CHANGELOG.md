# Changelog

All notable changes to this project will be documented in this file.

## v0.1.0 - 2026-03-20

Initial public release of Ralph.

### Highlights

- Introduced a plan-first autonomous issue-to-PR workflow for GitHub Issues.
- Added validator-gated completion so work is only considered done after validation passes.
- Added incremental execution with persisted orchestration state across workflow runs.
- Added Feishu ingress and notification support alongside GitHub-native issue and PR flow.
- Added bilingual documentation and localized runtime messaging.

### Included in this release

- GitHub Actions workflows for execution, scheduled scans, and automerge support
- core orchestration shell scripts and reporting helpers
- Feishu bridge and worker integration
- issue template, PR template, and open source community files
- brand assets and bilingual project documentation

### Open Source Readiness

- Removed owner-specific public content from repository runtime copy where applicable
- Added contribution, security, support, and conduct documentation
- Simplified the public git history for the open source release
