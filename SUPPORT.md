# Support

## Getting Help

Use GitHub Issues for:

- bug reports
- feature requests
- documentation fixes
- workflow or integration problems

When opening an issue, include:

- what you expected
- what happened instead
- relevant logs or screenshots
- repository and backend context

## Before Opening an Issue

- Read [README.md](./README.md)
- Read [README_CN.md](./README_CN.md) if you prefer Chinese
- Check existing issues and pull requests

## Feature and Design Discussion

For non-trivial design changes, open an issue first so the execution model, UX, and compatibility impact can be discussed before implementation.

## Security Issues

Do not report security problems in public issues. Follow [SECURITY.md](./SECURITY.md).
